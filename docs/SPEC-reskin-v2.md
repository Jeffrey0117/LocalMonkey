## 1. 品牌

| | 舊 | 新 |
|---|---|---|
| 站名 | `templatee.com` | **html模板大王** |
| 副標 | 模板商城 | 自己想一句短的（例：精選網頁模板） |
| 主色 | `#ee4d2d`（蝦皮橘） | **換掉**，見下 |

### 配色方向

不要橘。這是一個賣網頁模板的站，受眾是開發者/設計者，走**深色調 + 一個鮮明強調色**比電商橘更合適也更不像蝦皮。

建議：深靛藍／石板灰當底（`#1e1b4b`～`#312e81` 一類），強調色用亮一點的紫或青。**價格仍然用醒目色**（但不要紅橘）。

挑定之後**整套色票集中在 theme 的一個地方**（CSS 變數），之後要換色改一處就好。

## 3. 方案簡化

> 「方案的話　**別分什麼個人 企業**　**也別寫什麼授權的鬼**」

- **拿掉三選一的方案選擇器**（免費版 / 個人授權 / 企業授權）
- **拿掉所有「授權」字眼**（授權方案、授權範圍、授權對象、可轉授權、商業許可證…）
- 商品頁就是**一個價格**，直接買

`reskin_pricing` 的資料結構保留（之後可能還要分級），但預設只有一個方案，UI 不顯示選擇器。單一方案時不要畫出空的選擇區。

## 5. 「下載次數」一律改叫「售出次數」

商品頁規格表現在是：

```
標籤 / 上架日期 / 瀏覽次數 / 下載次數 / 商品編號
```

**「下載次數」改成「售出次數」**，數字不變。

這是展示層的字面改動，資料模型的 `stats.downloads` 欄位名不用動（它描述的是資料來源的語意）。

## 6. 購買列的按鈕

現在是：`加入購物車` / `立即購買`，下面另一排 `下載檔案` / `線上預覽`。

改成：

- **拿掉下面那排兩顆**（`下載檔案`、`線上預覽`）
- **`加入購物車` 改成 `預覽`** —— 點了開上游的預覽網址（`links.preview`）
- `立即購買` 留著

所以購買列只有兩顆：**預覽** ｜ **立即購買**。

## 7. 首頁無限載入

列表頁往下滾到底自動載入下一頁，不要頁碼。

- 需要一個回 listing JSON 的端點（例如 `GET /p/<site>/__reskin/listing?page=N`），前端 `IntersectionObserver` 觸發
- **保留無障礙與退路**：載入中要有狀態、失敗要有「重試」、沒有更多要顯示「已經到底了」
- 網址列要跟著更新（`history.replaceState`），重新整理不會跳回第一頁
- 上游有 54 頁，不要一次全抓

## 8. 金流（測試用）

> 「就外能接金流　讓我測試嗎」

**只做測試環境，不碰正式收款。** 這個站展示的是 templatemo 免費送的模板，正式收款是另一回事，等資料源換成使用者自己的模板庫再說。

實測（2026-11-19，從這台）：

- `https://paygate.isnowfriend.com/api/plans` → **200，連得到**
- `https://ccore.newebpay.com/`（藍新測試）→ 403（正常，根路徑本來就不開）
- 這台**沒有**任何本機金流專案

### 做法

`立即購買` → 走 **PayGate** 建立訂單 → 導到藍新**測試環境**付款頁 → 回跳成功頁。

- PayGate 的端點與金鑰**不要寫死在程式碼**，走 env（`LOCALMONKEY_PAYGATE_URL`、`LOCALMONKEY_PAYGATE_TOKEN`）
- 沒設 env → 按鈕維持現在的純前端示範行為，並在 UI 標示「未接金流（示範模式）」。**不要讓沒設定的人看到壞掉的按鈕**
- 金鑰只在伺服器端用，**絕對不准出現在前端或 HTML**
- 回跳的成功/失敗頁由我們自己渲染

> ⚠️ infra-map 記著「PayGate 的端點清單部分過時要實測」。**先打 `/api/plans` 看回應長相再寫**，不要照記憶寫。
